# Regulatory Scope Specification (49 CFR Part 395)

DCW Version 1 enforces U.S. FMCSA Property-Carrying Interstate Rules.

## Rules Enforced

1. **11-Hour Driving Limit** (§ 395.3(a)(3)(i))
2. **14-Hour Duty Window** (§ 395.3(a)(2))
3. **Mandatory 30-Minute Rest Break** (§ 395.3(a)(3)(ii))
4. **60/70-Hour Weekly Duty Limits** (§ 395.3(b))
5. **34-Hour Restart Provision** (§ 395.3(c)) — 34 consecutive OFF/SB hours including two home-terminal 1:00–5:00 AM periods (`DEFAULT_HOME_TERMINAL_TIMEZONE`, default `America/Chicago`)
6. **Split Sleeper Berth Option** (§ 395.1(g)(1))

## Explicit Exclusions

* Passenger-carrying rules (§ 395.5)
* Short-haul 150 air-mile exception (§ 395.1(e))
* Agricultural operations exception (§ 395.1(k))
* Intrastate non-federal variations
